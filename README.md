# Focus: Ваш Компаньон для Концентрации

**Focus** — это минималистичное приложение для захвата мыслей, созданное специально для людей с синдромом дефицита внимания и гиперактивности (СДВГ), а также для всех, кто ценит простоту и скорость.

🚀 **[Открыть приложение](https://focus-adhd.netlify.app)** (требуется HTTPS для доступа к камере/микрофону)

📱 **Установите как PWA на Android:** После открытия приложения в Chrome нажмите "Установить приложение" для нативного опыта.

## Философия

Людям с СДВГ часто приходят в голову блестящие идеи, но они могут так же быстро исчезнуть. Основная цель этого приложения — максимально сократить путь от возникновения мысли до её фиксации. Мы называем это "уменьшением когнитивного трения".

В разработку заложены три главных принципа:

1.  **Захват без усилий:** Интерфейс, основанный на интуитивных жестах (свайпах), позволяет мгновенно переключаться между режимами ввода (текст, голос, фото), не отвлекаясь на меню и кнопки.
2.  **Минимум отвлечений:** В приложении нет ничего лишнего. Открывая его, вы видите только зону для ввода. Никаких лент, уведомлений или сложных настроек. Это помогает оставаться в потоке и не терять мысль.
3.  **"Захвати сейчас, организуй позже":** Приложение сознательно разделяет процессы создания и просмотра заметок. Основной экран предназначен только для захвата идей. Просмотр и удаление вынесены в боковую панель, чтобы не прерывать творческий процесс.

## Ключевые Особенности

*   **Интерфейс на основе жестов:**
    *   **Свайп вверх:** Активирует камеру для фотозаметки.
    *   **Свайп вниз:** Открывает режим записи аудио.
    *   **По умолчанию:** Всегда готов к вводу текста.

*   **Мультимодальный ввод:** Сохраняйте свои мысли в удобном для вас формате:
    *   **Текст:** Для быстрых записей и идей.
    *   **Аудио:** Надиктовывайте мысли, когда неудобно печатать.
    *   **Фото:** Сфотографируйте то, что вас вдохновило или что нужно запомнить.

*   **Полная оффлайн-поддержка (Offline-First):**
    *   Приложение работает как PWA (Progressive Web App), его можно установить на главный экран.
    *   Все заметки хранятся локально в вашем браузере (используя IndexedDB), что гарантирует доступ к ним даже без подключения к интернету.

*   **Тактильный и звуковой отклик:**
    *   Лёгкая вибрация и звуковые сигналы подтверждают ваши действия, создавая приятный пользовательский опыт и давая уверенность, что команда выполнена.

*   **Продуманный дизайн для СДВГ:**
    *   **Низкая когнитивная нагрузка:** Не нужно принимать множество решений, чтобы сохранить мысль.
    *   **Фокус на одной задаче:** Экран всегда сосредоточен на одной функции — вводе.
    *   **Надёжность:** Оффлайн-подход гарантирует, что ни одна идея не будет потеряна из-за проблем с сетью.

## Как пользоваться

1.  **Текстовая заметка:** Просто откройте приложение и начните печатать. Нажмите "Save" для сохранения.
2.  **Аудиозапись:** Потяните экран вниз до упора, чтобы начать запись. Нажмите на иконку микрофона, чтобы остановить.
3.  **Фотография:** Потяните экран вверх до упора, чтобы сделать моментальный снимок.
4.  **Просмотр заметок:** Нажмите на иконку-гамбургер в левом верхнем углу, чтобы открыть список всех сохраненных мыслей.
