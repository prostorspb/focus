# Установка Focus ADHD Companion на Android

## Требования
- Android устройство с Chrome, Edge или другим браузером с поддержкой PWA
- Интернет соединение для первой установки

## Шаги установки

### 1. Откройте приложение в браузере
Откройте ссылку на приложение в браузере (Chrome рекомендуется):
```
http://your-deployment-url.com
```

### 2. Пройдите онбординг
При первом запуске вы увидите экран приветствия:
- Нажмите "Начать"
- На экране разрешений нажмите "Разрешить доступ"
- Браузер запросит доступ к **камере** и **микрофону**
- Разрешите доступ к обоим устройствам
- ✅ После предоставления разрешений появятся зеленые галочки
- Прочитайте инструкцию по использованию
- Нажмите "Понятно, начнём!"

### 3. Установите PWA на домашний экран

#### Вариант A: Chrome (рекомендуется)
1. Нажмите на значок меню (три точки) в правом верхнем углу
2. Выберите "Установить приложение" или "Добавить на главный экран"
3. Подтвердите установку
4. Приложение появится на домашнем экране как нативное

#### Вариант B: Автоматическое предложение
- Chrome может автоматически предложить установку через баннер внизу экрана
- Нажмите "Установить" в баннере

### 4. Запустите как нативное приложение
- Найдите иконку "Focus" на домашнем экране
- Запустите приложение
- Оно откроется в полноэкранном режиме без адресной строки браузера

## Важно о разрешениях

### Одноразовый запрос разрешений
После того как вы предоставили разрешения на камеру и микрофон:
- ✅ Разрешения **сохраняются навсегда** для установленного PWA
- ✅ При следующих запусках разрешения **НЕ будут запрашиваться снова**
- ✅ Приложение работает как **нативное** с постоянным доступом к камере/микрофону
- ✅ Экран онбординга показывается **только один раз**

### Если пропустили запрос разрешений
Если вы нажали "Пропустить" на экране разрешений:
1. Откройте меню браузера (три точки)
2. Перейдите в "Настройки сайта" или "Информация о сайте"
3. Найдите "Разрешения"
4. Включите "Камера" и "Микрофон"
5. Перезапустите приложение

### Сброс онбординга (для тестирования)
Чтобы снова увидеть экран приветствия:
1. Откройте приложение
2. Откройте DevTools (если в браузере)
3. Перейдите в Application → Local Storage
4. Удалите ключ `onboarding_completed`
5. Обновите страницу

## Преимущества установленного PWA

После установки приложение работает как нативное:
- 📱 Запуск с домашнего экрана
- 🚀 Полноэкранный режим (без адресной строки)
- ⚡ Быстрый запуск
- 💾 Работа офлайн (после первой загрузки)
- 🔐 Постоянные разрешения (не запрашиваются повторно)
- 📷 Мгновенный доступ к камере
- 🎤 Мгновенный доступ к микрофону
- 💪 Работает в фоне (WakeLock предотвращает блокировку экрана)

## Удаление приложения

### Android
1. Найдите иконку Focus на домашнем экране
2. Нажмите и удерживайте
3. Выберите "Удалить" или "Удалить приложение"
4. Подтвердите удаление

Или через настройки Chrome:
1. Откройте Chrome
2. Меню → Настройки → Установленные приложения
3. Найдите Focus
4. Нажмите "Удалить"

## Устранение неполадок

### Приложение не предлагает установку
- Убедитесь, что используете HTTPS (или localhost для разработки)
- Проверьте, что manifest.webmanifest загружается корректно
- Очистите кэш браузера и обновите страницу

### Разрешения не работают
- Убедитесь, что используете HTTPS
- Проверьте настройки сайта в браузере
- Попробуйте переустановить приложение

### Приложение не работает офлайн
- Убедитесь, что Service Worker зарегистрирован
- Проверьте в DevTools → Application → Service Workers
- При первом запуске нужен интернет для кэширования

## Локальная разработка и тестирование

Для локального тестирования установки:
1. Запустите `npm run dev`
2. Откройте на Android через локальную сеть: `http://192.168.x.x:3000`
3. Или используйте `npm run build && npm run preview` для production билда
4. Для тестирования HTTPS используйте ngrok или Cloudflare Tunnel

**Примечание**: Chrome на Android требует HTTPS для многих PWA функций (кроме localhost).
